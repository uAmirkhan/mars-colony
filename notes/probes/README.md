# Незаконченные пробы тестировщика

Круг качества 1, стадия поиска. Агент-тестировщик прерван лимитами сессии
до отчета. Это его разведочные наброски, а не готовые находки.

Расширение `.ts.txt` намеренно: файлы не должны попадать в прогон тестов,
но и терять их нельзя — там начатая работа.

**Зацепка, которую стоит проверить первой:** в `sim-probe2.ts.txt` стоит
комментарий «Помидоры убраны из игры целиком: открываются позже потолка MVP».
Если это подтвердится, часть товарного субстрата в срезе недостижима.
