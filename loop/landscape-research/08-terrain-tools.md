# Направление 8: отдельные программы-генераторы ландшафта

Разведка для витрины марсианской колонии (изометрический сити-билдер). Задача рельефа: связный ландшафт с ровными площадками под застройку, пайплайн — карта высот на вход в Blender-скрипты.

Дата разведки: 2026-08-09. Часть цифр — по официальным страницам вендоров на эту дату, часть — по кэшированным описаниям поисковика, где явно указано "без проверки" в тексте — доверять с осторожностью и перепроверить перед решением, если это станет критичным.

> **Правка от владельца (после первого прохода):** ограничение "бюджет — 0" снято. Платные редакции ниже разобраны как реальные кандидаты на покупку, не как справочные цифры. Раздел с полными характеристиками платных версий — в конце файла, перед источниками.

### Gaea (QuadSpinner)

- **Цена:** Community (бесплатная) / Indie $99 / Professional $199 / Enterprise $299. Лицензии бессрочные (perpetual), без подписки.
- **Что урезано в бесплатной версии:** сборка рельефа (build) ограничена 1024×1024. Тайловая сборка (для склейки в большие карты) недоступна вообще — только в Professional/Enterprise.
- **Коммерческое использование:** по официальной странице сравнения (quadspinner.com/compare) на Community-редакции **коммерческое использование не разрешено** ("Commercial Use: Not permitted"). Внимание: в поисковой выдаче попадались противоречивые старые формулировки ("free edition licensed for commercial use, export capped at 1K") — это, похоже, отголосок политики Gaea 1.x, где бесплатная версия ниже определённого порога дохода разрешала коммерцию. В текущей версии (Gaea 2.x/3.x) официальная таблица говорит "не разрешено". Для витрины-портфолио это означает: технически можно сгенерировать рельеф бесплатно, но по букве лицензии использовать результат в публичном коммерческом проекте — рискованно без покупки Indie ($99).
- **Водяной знак:** в найденных источниках не упомянут (в отличие от Terragen/Houdini) — вероятно, его нет, ограничение чисто по разрешению.
- **Windows:** да, нативно.
- **Терраса/плато:** есть штатные инструменты. Node "Stratify" на малой силе даёт множество мелких террас/наслоений; сильная терраса на среднем уровне режет крутые ступени (но не всегда плоские верхушки — нужно комбинировать с выравнивающими нодами). Erosion-нода имеет Selective Processing (маска по уклону/высоте) — можно эродировать только крутые склоны, оставляя плоские участки нетронутыми, это прямой путь к "эрозия + ровные плато" одновременно.
- **Автоматизация/CLI:** есть полноценный CLI (два интерфейса — для UI и для Build Swarm), Batch Builds, Automation Mode для встраивания в пайплайн. НО: "Automation" как фича явно отмечена доступной только в Professional/Enterprise, не в Community/Indie — то есть бесплатный автоматизированный батч-рендер скорее всего недоступен, только ручная сборка через UI.

### Houdini Apprentice (SideFX)

- **Цена:** бесплатно.
- **Ограничения:** строго **не коммерческое** использование ("students, artists and hobbyists... personal non-commercial projects"). Лицензия действует 30 дней и продлевается вручную сколько угодно раз, но остаётся некоммерческой.
- **Водяной знак:** да, при рендере и сохранении на диск — Apprentice ставит водяной знак.
- **Террейн-инструменты:** полноценный Heightfield-тулсет доступен, включая специально то, что нам нужно:
  - **HeightField Terrace** — режет ступенчатые террасы на склонах, с 18.0 переписана, настраиваемый шаг ступени, плюс режим fade (плавный переход рельефа в террасу). Выдаёт две маски: "mesa" (где террейн выровнен) и "cliffs" (границы обрезанных зон) — то есть прямо возвращает маску плоских площадок, что удобно для последующей расстановки зданий.
  - **HeightField Flatten** — берёт маску и делает выбранную область идеально плоской (для footprint под геометрию) — это ровно "ровное плато под здание".
  - Плюс erosion-ноды и HeightField Mask by Feature для селективного применения.
- **Дополнительное ограничение:** цифровые ассеты (HDA), созданные в Apprentice, нельзя использовать с Houdini Engine/Engine Indie; сторонние рендереры недоступны.
- **Вывод:** технически — лучший в списке инструмент именно под задачу "эрозия + ровные плато" (Terrace + Flatten + маски это готовое решение), но лицензия Apprentice **прямо запрещает коммерческое использование результата**, что для витрины портфолио — стоп-фактор, если витрина хоть как-то монетизируется или используется как публичное коммерческое портфолио. Если это чисто демонстрационный некоммерческий пет-проект — юридически можно, но всплывающий водяной знак на любом рендере/скриншоте — практическая помеха для чистой презентации.

### Открытые библиотеки шума и GitHub-генераторы

- **libnoise** — старая C++ библиотека (последний стабильный релиз 1.0.0, копирайт 2003-2005), лицензия LGPLv2/GPLv2. По косвенным признакам (метаданные в выдаче датированы 2013 годом) **не поддерживается активно**. Для новых проектов на Windows в 2026 году — плохой выбор: собирать древний C++ без вендорской поддержки ради базового Перлина смысла нет, когда есть современные легковесные альтернативы.
- **FastNoiseLite** (Auburn) — актуальная, активно поддерживаемая, кроссплатформенная библиотека шума. Существует на C, C#, C++, Java, JS, Rust, Go, GLSL/HLSL и ещё десяток языков (включая даже PowerShell). Есть визуальный тестер настроек (auburn.github.io/FastNoiseLite). Свободная лицензия (MIT), удобна для интеграции прямо в Blender-скрипты через Python-порт или как C-модуль.
- **python-noise (`pip install noise`)** — классический пакет Перлин/Симплекс для Python, но **на Windows требует компиляции C-расширения** (нужны MS Visual C++ Build Tools) — известная точка боли для непрограммистской машины. Проект давно не поддерживается, бинарники под новые версии Python может не быть.
  - **Альтернатива без боли компиляции:** `opensimplex` (`pip install opensimplex`) — чистый Python-порт (плюс numpy для векторизации, опционально numba для скорости), тестируется на Windows/Linux/macOS в CI, ставится без компилятора. Это предпочтительный вариант под наше ограничение "Windows 11, никакого возни с тулчейнами".
- **GitHub-генераторы рельефа на Python:**
  - **dandrino/terrain-erosion-3-ways** (MIT) — чистый Python 3, numpy/scipy. Три метода: (1) частицевая гидравлическая эрозия (перенос воды и осадка по итерациям), (2) GAN на TensorFlow, обученная на реальных данных USGS (не годится — нам нельзя NASA/геоданные и вообще overkill), (3) генерация речных сетей через Пуассоновский диск + триангуляцию Делоне с последующей резкой долин. Первый и третий методы — ровно то, что нужно: чистый Python/numpy, без внешних приложений, результат — .npy карта высот 512×512, конвертируемая в PNG. Готовый референс-код для нашего пайплайна.
  - **sp4cerat/Terrain-HeightMap-Generator** — C++ генератор с эрозией, если понадобится более быстрый нативный вариант, но это уже не "чистый Python".

## Главный вопрос: достаточно ли обычного Python на шуме Перлина

**Ответ: да, для нашей задачи достаточно, но с одной оговоркой — "чистый Перлин без обработки" не даёт ни правдоподобной эрозии, ни ровных плато сам по себе; нужно 2-3 несложных дополнительных шага поверх шума, и все они делаются в том же Python/numpy без единой внешней программы.**

Почему это не "неделя коту под хвост", а обоснованный вывод:

1. **Базовый рельеф.** Слоёный (октавный) Перлин/симплекс-шум (`opensimplex`, ставится без компилятора на Windows, или самописный FastNoiseLite-порт) с 4-6 октавами и доменным варпингом (domain warping — сдвиг координат сэмплирования вторым слоем шума) даёт связный, не-повторяющийся базовый рельеф. Это 20-30 строк numpy-кода, задача одного вечера.

2. **Плато под застройку — это НЕ работа шума, это отдельный проход постобработки**, и он проще, чем кажется:
   - **Террасирование через квантование высоты:** `h_terraced = floor(h / step) * step` (плюс сглаживание на границах ступеней) — даёт ступенчатый рельеф за одну строку кода. Это ровно то, что делает Gaea Stratify и Houdini Terrace внутри, просто без красивого UI.
   - **Явные плоские площадки под конкретные здания:** раз пайплайн всё равно управляется скриптом (мы сами решаем, где ставить дома), проще не ждать, что шум "случайно" даст ровное место, а явно накладывать маску (круг/прямоугольник в месте будущего здания) и внутри неё выравнивать высоту до среднего/целевого значения с растушёванным краем (falloff) — это и есть аналог Houdini HeightField Flatten, реализуемый в 15-20 строк.

3. **Эрозия.** Правдоподобную гидравлическую эрозию без внешних программ дают открытые референс-реализации на чистом Python/numpy — например, `dandrino/terrain-erosion-3-ways` (MIT, частицевый метод переноса воды и осадка). Это готовый алгоритм, который можно взять почти as-is и адаптировать под масштаб карты. Уровень сложности — на порядок ниже, чем изучение чужого UI (Gaea/World Machine), потому что код читается построчно и меняется под конкретную нужду (например, ограничить силу эрозии в зонах, которые мы уже пометили под застройку — тот самый "selective erosion by mask", что в Gaea и Houdini является платной/сложной фичей, а в своём коде — просто "не трогать пиксели, где mask==1").

4. **Порядок операций, который снимает конфликт "эрозия против плоских площадок":** сначала шум → затем эрозия по всей карте → затем поверх результата накладываются плато (террасирование под кластеры застройки + точечное выравнивание под конкретные здания с растушёванным краем). Так эрозия успевает дать реалистичные потёки и неровности природного рельефа, а плато прорезаются последним проходом и гарантированно ровные — ровно то сочетание, которое в специализированных программах требует их selective-processing масок, а тут получается просто порядком шагов в скрипте.

**Практический вывод:** не нужно тратить неделю на освоение Gaea/World Machine/Houdini ради лицензионно чистого результата. Нужный набор — `opensimplex` (или собственный порт FastNoiseLite) + доменный варпинг + террасирование квантованием + точечный flatten по маске + частицевая эрозия (референс — dandrino/terrain-erosion-3-ways). Всё это стандартный numpy, ставится на Windows без компиляторов (кроме опционального numba), результат — обычный PNG/EXR heightmap на вход в Blender-скрипты, никаких лицензионных ограничений на использование в коммерческой витрине, потому что весь код написан и запущен нами.

Единственный сценарий, где стоит вернуться к специализированной программе — если через 1-2 недели окажется, что качество самодельной эрозии/террас визуально не дотягивает и время на доводку алгоритма съедает больше, чем стоила бы лицензия Gaea Indie ($99, разовая, без подписки) для конкретно этой задачи. Но начинать имеет смысл с Python.

## Что именно дают платные инструменты сверх самописного Python-шума

Владелец прав спросить не только "работает или нет", но и "за что конкретно платят". Вот честный список, что покупается:

1. **Качество и скорость гидравлической эрозии.** Самописная частицевая эрозия (dandrino/terrain-erosion-3-ways и подобные) даёт правдоподобный результат, но это упрощённая модель без персистентной скорости потока, без раздельного расчёта переноса и осаждения по вязкости, без многопроходной тепловой+гидравлической комбинации. Gaea/Houdini/Instant Terra используют выверенные годами симуляционные ядра (в Instant Terra — GPU-ускоренная гидравлика, у Gaea — комбинация Rivers/Sediment/Thermal нод), которые на близком плане дают более убедительные детали: слоистость осадочных пород, реалистичные дельты рек, эрозионные потёки на разных масштабах одновременно. На среднем/дальнем плане изометрической витрины разница может быть не критична; на близком плане (если камера подъезжает к рельефу) — заметна.

2. **Готовые пресеты и художественная библиотека.** В Gaea/World Machine/World Creator — сотни pretested пресетов (горы, каньоны, дюны, вулканические поля и т.д.), собранных художниками. Марсианский рельеф — не земной биом, придётся всё равно кастомизировать, но пресет часто даёт хорошую стартовую точку (кривые эрозии, распределение шума по масштабам), которую иначе пришлось бы подбирать вручную итерациями.

3. **Вырезание плато/террас — не сама возможность, а инструмент.** В самописном Python это `floor(h/step)*step` и ручная маска — работает, но плоское квантование даёт геометрически "чистые" ступени без органичности (без выветренных краёв, без осыпей на границе плато). Houdini HeightField Terrace/Flatten с параметрами fade/mesa/cliffs дают процедурно проработанный переход "плато → откос → естественный склон" за счёт того, что инструмент десятилетиями дорабатывался именно под этот художественный эффект. Разницу видно в первую очередь на границе площадки — у самописного варианта она будет выглядеть более "инженерно", у Houdini/Gaea — более естественно, если не потратить время на ручную доводку той же границы в коде.

4. **Итерационная скорость через визуальный нод-граф.** Это, возможно, самое ощутимое отличие не в качестве, а в скорости работы: в Gaea/Houdini/World Machine художник двигает слайдер и видит результат за секунды в 3D-вьюпорте. В самописном Python-скрипте каждая правка параметра — это перезапуск скрипта и пересчёт (для эрозии на большой карте это может быть минуты). Если рельеф планируется долго и часто дорабатывать вручную "на глаз" — нод-граф экономит время итераций. Если параметры один раз подобраны и дальше карта генерируется программно под разные конфигурации колонии — эта разница исчезает, потому что скрипт как раз и рассчитан на пересчёт без ручного участия.

5. **Детализация под самый близкий план (текстуры, normal maps, curvature masks).** Если камера когда-нибудь подойдёт близко к поверхности, Gaea/Houdini умеют генерировать сопутствующие карты (curvature, flow, occlusion, slope) для процедурного текстурирования грунта — этого голая карта высот из Python не даёт, их пришлось бы либо считать самим (несложно средствами numpy — куда взять производные по градиенту), либо генерировать в самой программе.

**Вывод по этому разделу:** платишь не за то, что задача "эрозия + плато" вообще решаема — она решаема бесплатно, — а за (а) более убедительную эрозию на крупном/близком плане за счёт зрелых симуляционных ядер, (б) более органичный, художественно доведённый край плато вместо инженерно-ровного, (в) скорость визуальной итерации при ручной доводке, (г) сопутствующие карты для текстурирования. Для казуальной изометрической витрины, где камера не подлетает вплотную к грунту и рельеф генерируется программно под конкретные слоты застройки, пункты (а) и (б) — это разница "заметно при пристальном разглядывании", не "не работает без покупки". Если проект вырастет до требований крупного плана — тогда Houdini Indie ($299/год) или Gaea Professional ($199 разово) первыми кандидатами на апгрейд именно ради этой органичности.
