# Проба оркестратора: гейт GLB -> FBX снят

снят одной проверкой.

## Вопрос

Переживает ли запеченная PBR-текстура переход GLB -> FBX. Без этого Unity не
получит ни одной модели: пакета glTF в проекте нет, редактор читает только
FBX, OBJ, DAE, BLEND.

## Как проверено

`design/tools/glb-to-fbx.py`. Проверка построена так, чтобы ее нельзя было
обмануть: FBX экспортируется, потом сцена сбрасывается в пустую, все картинки
из памяти удаляются, и FBX читается заново с нуля. Если текстура не доехала —
объект приедет серым, и это видно на кадре.

```
"C:\Program Files\Blender Foundation\Blender 5.2\blender.exe" -b ^
  -P design/tools/glb-to-fbx.py -- ^
  design/models/grunt-regolit-4.glb выходная_папка 20000
```

## Вывод

```
[1-iz-glb] треугольников 20000 | текстуры в памяти: Image_0 4096x4096, Image_1 4096x4096
ЭКСПОРТ grunt-regolit-4.fbx 24.2 МБ
[2-iz-fbx] треугольников 20000 | текстуры в памяти: Image_0 4096x4096, Image_0.001 4096x4096
ГАБАРИТ ПОСЛЕ FBX 1.979 x 2.000 x 1.907, основание z=-0.0000
```

Кадр: `design/models/osmotr/fbx/grunt-regolit-4-2-iz-fbx.png` — объект пришел
с текстурой, оранжевая порода и серые борта на месте, серым не стал.

**Гейт пройден.** Рабочие ключи экспорта, они существенны:
`path_mode='COPY'`, `embed_textures=True`, `axis_forward='-Z'`, `axis_up='Y'`,
`apply_unit_scale=True`.

Заодно закрыто: посадка основания в ноль и вписывание в клетку 2.0 переживают
переход, габарит после FBX 1.979 x 2.000 x 1.907 при основании z = -0.0000.

## Что проба НЕ закрыла, и это надо доделать

1. **На 20000 треугольниках поверхность уже рвется.** На кадре по краям видны
   мелкие треугольные лоскуты и задиры — это след децимации с 482 тысяч, то
   есть сокращения на 96 процентов. Форма держится, но чисто это не назвать.
   Нужен подбор бюджета для моделей грунта отдельно: возможно 40-60 тысяч.
2. **Unity этот FBX еще не открывала.** Проверено чтением обратно в Blender,
   а не редактором. Родной импортер Unity может повести себя иначе с
   внедренными текстурами.
3. Проба сделана на одной модели из пяти грунтов.

## Кто продолжает

Программист, с этого места. Скрипт `design/tools/glb-to-fbx.py` — рабочая
основа, а не набросок: его надо довести до инструмента (батч по списку
принятых, отчет по каждой модели, разумный бюджет треугольников) и доказать,
что редактор Unity читает результат.
