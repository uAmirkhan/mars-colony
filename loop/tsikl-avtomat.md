# Автоматический цикл Mars Colony: журнал кругов

Регламент цикла — `agent_docs/mars-beskonechnyy-tsikl.md`.
Свод правил — `design/doktrina-rasstanovki.md`.

## Как устроен круг

```
1. Четыре критика смотрят кадр и замер          (параллельно)
2. Ведущий теххудожник сводит вердикты в список правок числами
3. Программист Unity реализует правки в ColonyOursBuilder.cs
4. Я перезапускаю редактор, собираю сцену, снимаю кадр, меряю
5. Кадр уходит критикам следующего круга
```

Шаги 1-3 идут оркестрацией, шаг 4 — только мной: редактор Unity один на всех и
параллельного доступа не переживает.

Цель, заданная владельцем: **вся картина целиком — живая, насыщенная разными
объектами и зданиями, приятная глазу и гармоничная.** Ориентир — Township.

## Что мерится каждым кругом

| Метрика | Цель | Откуда |
|---|---|---|
| пересечения объектов | 0 | лог сборки |
| плотность кластера | 65-80% | лог сборки |
| нарушения регламента декора | 0 | лог сборки |
| вызовы отрисовки | не больше 120 | metrics.json |
| треугольники | не больше 250 000 | metrics.json |
| построек у полотна дороги | 25-35% | лог сборки |
| признаков жизни разряда A | не меньше 1 | глазом по кадру |
