# Быстрая шкала сцены ColonyOurs (наши ассеты)

Одно число 0-100 = сумма пяти критериев по 20. Порог цикла: 90.
Оценивает арт-инспектор по кадрам colony-ours-*.png и сцене.
Каждый вычет - с местом (объект, координаты) и ценой в баллах.

## 1. Логика раскладки (20)
Каждый объект стоит там, где он по смыслу живет: шаттл на посадочной
площадке, дрон у площадки, буровые у карьера, жилье кварталом, заводы
промзоной, лед полем. Вычеты: объект без смысловой связи (-3),
шаттл/техника не на площадке (-5), зоны перемешаны (-5).

## 2. Земля (20)
Не читается ни подносом, ни калейдоскопом, ни пластилином. Вычеты:
видимый регулярный узор тайлинга (-5), артефакты сетки/ступени (-4),
голые пустые углы без причины (-3), земля спорит по стилю с моделями (-8).

## 3. Посадка и стыки (20)
Ничего не парит, не тонет, не торчит блоком. Плиты-основания врастают.
Вычеты: парение/утоп (-4 за случай), объект-на-подложке торчит постаментом
(-4), пересечения моделей (-4).

## 4. Свет и целостность стиля (20)
Один свет для всех, запеченные тени не спорят с солнцем сцены, ни один
объект не выглядит пришлым. Вычеты: двойные тени читаются (-5), объект
выбивается тоном/насыщенностью (-4), пересвет/чернота зон (-4).

## 5. Наполнение (20)
Большинство пригодных ассетов на карте, пустоты работают паузами, а не
дырами. Блины (7 штук) НЕ ставить - их отсутствие вычетом не считается.
Вычеты: центр/угол кадра пустует без причины (-4), меньше 15 уникальных
ассетов в сцене (-5), повтор одного ассета читается копипастой (-3).

## Процедура
Инспектор: пять чисел + вычеты с местами -> loop/ours/score-N.md.
Оркестратор чинит по вычетам, пересборка, следующий замер.
Стоп: score >= 90 два замера подряд, либо вычет требует решения владельца.
