# Три критика по сцене после сборки сетей (2026-08-26)

Каждый смотрел рендеры `zamer-kadra/j-*.png` один раз. Здания — константа заказчика, поэтому пункты с переносом зданий отклонены.

## Критик 1 — планировка и логика места

1. Буровая на льду и вышка в карьере вне дорожной сетки. → ВЗЯТО: подъезд `podezd-burovaya` от западной улицы к буровой и цистернам; пандус к карьеру уже доходит до кромки ямы.
2. Теплицы без плитки у входов. → ОТКЛОНЕНО: теплицы смотрят на южную улицу (2.4 м) и главную (1.2 м), ближе некуда без сноса.
3. Белой линии кислорода не видно. → ЧАСТИЧНО: линия есть (север льда → башня), критик не увидел из-за ракурса. Добавлены ветки к куполам 2 и 3; купол 1 не подключён намеренно — это задание на экране.
4. Трубы режут плитку по диагонали. → ОТКЛОНЕНО: все трубы осевые, под дорогами разрывы; диагональ — перспектива камеры.
5. «Круглый диск-резервуар» без трубы. → Это здание-гриб; ВЗЯТО как вода к грибу.
6. Ангар техники без топлива. → Критик имел в виду склад-ангар; ВЗЯТО: оранжевая труба от малых баков карьера к складу-ангару.
7. Гусеничная техника далеко от ангара. → ОТКЛОНЕНО: это ледовые резчики, работают на льду.
8. Перила вышки низкие. → В бэклог ассетов.
9. Трап открытого шаттла без дороги. → ОТКЛОНЕНО: между площадкой и бункерами 2.4 м, полоса не проходит; шаттл «сел в поле».
10. Сеть без ветвлений. → ОТКЛОНЕНО: водяная магистраль ветвится на три купола, три теплицы, завод, башню, гриб.

## Критик 2 — ландшафт

1. Кромка снега — ровная маска. → ВЗЯТО: перлин ±1.6 м по расстоянию до кромки.
2. Дальняя кромка карты плоская. → ВЗЯТО: холмы 3–5 м по реальной кромке карты.
3. Круглая проталина с валуном. → ВЗЯТО: это остаток старой ямы скважины; валун снят, яма засыпана.
4. Карьер плоский. → ОТЛОЖЕНО: дно −2.3 м, отвал есть; углубление трогает вышку заказчика.
5. Дороги без фаски. → ОТЛОЖЕНО (бордюры есть).
6. Уступ площадок. → ОТЛОЖЕНО: растушёвка 2 м уже стоит.
7. Льдинки одного калибра. → ВЗЯТО: три класса 0.5/0.9/1.5 м, джиттер ±1 м.
8. Контактные тени слабые у цистерн. → ВЗЯТО: альфа 0.6 для цистерн.
9. Гребни как забор. → ВЗЯТО: высота ×0.7–1.3, поворот ±12°.
10. Камни одного калибра. → ВЗЯТО: масштаб ×0.6–1.4 по каждому.

## Критик 3 — кадр и первые секунды

1. Нет здания-акцента. → ВЗЯТО: башня в песочный акцент.
2. Семьдесят процентов построек одного цвета. → В бэклог: семейства цветов по типу здания.
3. Иконки хаба без пиктограмм. → В бэклог интерфейса.
4. Здания режутся рамкой. → ВЗЯТО: отъезд камеры на 15% по оси взгляда.
5. Контраст ресурсной панели. → В бэклог интерфейса.
6. Трубы поверх дорог. → ОТКЛОНЕНО: под дорогами разрывы.
7. Угол камеры крут. → ОТКЛОНЕНО: 44° — угол Township, задан заказчиком.
8. Панель задания впритык к низу. → ВЗЯТО: +48 px.
9. Колонисты сливаются с грунтом. → ОТЛОЖЕНО: белые скафандры на оранжевом читаются.
10. Четыре равнозначных кластера. → ОТКЛОНЕНО: требует переносов.
