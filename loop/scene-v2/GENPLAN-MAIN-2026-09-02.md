# Генплан MAIN v1 — черновик ведущего, 02.09.2026

Решения заказчика (02.09, опрос): новый генплан целиком; вода — одна магистраль
буровая→цистерны, остальные трубы снять; электричество кабелем от гриба,
кислород баллонами; весь лёд заменить на гранёный led-gen из Blender; три
тоннельных модуля сшивают купола в одну цепь. Мебель сцены — в
`INVENTAR-MAIN-2026-09-02.md`, текущий кадр — `mars-unity/zamer-kadra/main-20-dorogi.png`.

Камера смотрит с юго-востока на северо-запад. Ближний край кадра — юг/восток,
дальний — лёд на северо-западе. Экранная «ось вверх» ≈ мировое (−0.64, +0.77).

## Логика места (сюжет колонии одной фразой)

Шаттл привозит людей и увозит товар → товар делает завод из урожая теплиц →
теплицы и жильё едят электричество солнечной станции и воду из льда → воду
бурят на ледяном поле, породу — в карьере. Читать кадр снизу вверх: порт →
дом → ферма → фронтир.

## Совет по v1 (геймдизайнер + продюсер, 02.09) — решения ведущего

Принято:
- Камера — вторым шагом, до геометрии (продюсер): всё дальше принимается по кадру.
- Дороги чинятся материалом, не геометрией (оба): тёплая земляная палитра,
  спина брусчаткой, рукава утрамбованным реголитом, бордюр мягче. Заказчик
  жаловался на цвет и грубость, не на форму.
- Купол C и башня не стыкуются сами (щель 0.5 м по x и z) — третий тоннельный
  модуль ставится между C и башней; восточный шлюз снят.
- Купола развести по тону в том же проходе, что и позиции (геймдизайнер).
- Тупик воды у цистерн (геймдизайнер): решается дроном-водовозом на маршруте
  цистерны → купола, не второй трубой — решение заказчика «одна линия» держится.
- Подъезды: к заводу от ul-yug (маршрут шаттл → спина → завод), к ангару
  ледовой техники от ul-sever.
- Вторая панель вычеркнута. Башню на −0.4 м не двигаем.
- Тоннели не тянуть: шаг куполов подобран под длину 4.3 м; пилот на одном.
- Лёд: только видимая часть поля первым заходом; три новые формы, не больше.
- Чужие дети `kupol-grib` (dorogi_sveden, dorogi-razobrannye) — в архивный корень.

Отклонено:
- Дорога шаттл → завод напрямую по z≈−20 (геймдизайнер): вторая улица
  параллельно ul-yug захламит нижнюю треть; маршрут идёт через спину.
- Технический настил с жёлто-чёрной кромкой (вариант 3 дорог) — чужой язык.
