# Приёмка UI-34, этап 3, блок 1 «полировка» (2026-09-05)

Метод: Python (Pillow/numpy), прямой замер по пикселям кадра, без правок кода/сцены. Кадры окна — 1600x900, серия из Play — 2588x1043 (проверено по факту, см. п.4). Рамка замера указана в каждом пункте.

## 1. P8, склад — отступ кнопки РАСШИРИТЬ от нижней кромки панели

Кадр: `etap3-sklad-4.png` (1600x900).

Рамка замера: нижний край кнопки — по колонкам x=980..1200 (тёмно-зелёная обводка кнопки, вне зоны скругления её углов), устойчиво **y=847**. Нижняя кромка панели (граница персикового бордюра и марсианского фона) — на плоском участке x=630..940 устойчиво **y=872** (проверено на 31 колонке, значение не плавает). Прямо под кнопкой, x=1050..1100 (левее правого скругления панели): y=870-871.

Отступ = 872 − 847 = **25 px** (на плоском участке; у правого края кнопки падает до 17-20 px — панель там уже входит в скругление угла).

Цель по спеке: 30-35 px.

**Вердикт: НЕ ПРИНЯТО.** Не хватает 5-10 px до нижней границы коридора. Прошлая правка («+4 px», см. OTCHET-etap3.md UI-34) продвинула кнопку, но недостаточно.

## 2. P1, HUD — видимый диаметр медальонов к высоте капсулы

Кадр: `etap3-hud-6.png` (1600x900).

Рамка замера — капсулы: тёмная пилюля-трек, замер по колонкам x=125..160 (капсула звезды «0/12») и x=1310..1350 (капсула монеты «50»), вне зоны текста. Верх/низ капсулы (чистый переход тёмного в фон, без сглаживания) — **y=24 → y=73** в обоих случаях, высота **50 px**.

Рамка замера — медальоны: по кремовой обводке медальона (RGB≈251,235,186), полный диапазон по всем колонкам звезды/монеты (включая нижние «лапы» звезды и нижнюю дугу монеты) — **y=8 → y=89** в обоих случаях, высота **82 px**.

Соотношение: звезда 82/50 = **1.64×**, монета 82/50 = **1.64×**. Цель: 1.6-1.7×.

**Вердикт: ПРИНЯТО.** Оба медальона попали в коридор (было 1.36-1.44×, коэффициенты 1.2/1.125 сработали). Побочно: выступ над/под капсулой вышел ровно 16 px с каждой стороны (в SPISOK записывалось пожелание 18-20 px) — критерий этого захода это коэффициент 1.6-1.7×, он выполнен; выступ в px не был явным пунктом приёмки, фиксирую как наблюдение, не как отказ.

## 3. P3б, HUD — контраст пустого трека опыта

Кадр: `etap3-hud-6.png`, капсула звезды.

Рамка замера: y=59..67 внутри капсулы, x=118..165 (чистый участок, без текста «0/12»). Высота светлой полосы-трека — ровно **9 строк (9 px)**, совпадает со спекой. Цвет трека [39,36,32] против заливки капсулы вокруг [33,28,2] (тот же x-диапазон, y=47..57).

Контраст трек/заливка по WCAG-люминансу ≈ **1.1:1** (практически неразличимо по яркости), абсолютная разница каналов ≈15/255. Для контекста: заливка/белый текст ≈17:1, заливка/фон ≈10:1 — элементы, которые обязаны читаться, контрастнее трека на порядок.

Глазом (кроп `track_zoom.png`, сохранён в скретчпаде): трек виден как едва заметная тёмно-серая полоска, не конкурирует ни с цифрами, ни с медальоном.

**Вердикт: ПРИНЯТО.** Высота точно по спеке (9 px), контраст низкий и по числу, и по глазу — трек ушёл на второй план, не читается как «мёртвый груз».

## 4. P14, шаттл — пыль при посадке

Кадры: `etap3-shattl-pyl-montazh.png` (5 стоп-кадров), серия `anim/shattl7/shattl-00..29-*.png`. Факт по диску: **30 файлов (00-29), 000-523 мс** — в задаче было заявлено «29 кадров, 0-505 мс», по факту на один кадр больше и до 523 мс; несущественно, но фиксирую расхождение с описанием. Плюс `diff_heat.png`.

Метод: попиксельный diff кадра 00 (000 мс) и кадра 28 (505 мс), связные компоненты (scipy.ndimage.label, порог |Δ|>40 по сумме 3 каналов); отдельно — средний цвет ядра каждого клуба (топ-15% самых засвеченных diff-пикселей) против того же места на кадре 00 (чистый грунт/плита).

**Клубы видны:** да. Найдено **5 отдельных клубов** диффом, не 7:
- два у кокпита сверху (один тонкий вытянутый, один округлый рядом — расположены впритык, но это два разных пятна);
- один слева на грунте;
- один снизу по центру на грунте;
- один справа на бортике площадки (визуально разрезан пополам приподнятым краем площадки — это один клуб, просто перекрыт геометрией борта в середине).

**Снаружи силуэта шаттла:** да. Прямоугольник корпуса на кадре — x627-795, y597-711; все 5 клубов лежат вне этого прямоугольника, ни один не спрятан под корпусом.

Оставшиеся 2 из заявленных 7 — вероятно на дальней стороне кольца, скрытой корпусом от этой камеры; по имеющимся кадрам (камера не поворачивается) подтвердить или опровергнуть их существование нельзя.

**Стиль:** мягкие рваные по контуру облака (см. кропы `puff_left_zoom.png`, `puff_bottom_zoom.png` в скретчпаде) — не квадраты, не сетка точек. Старые дефекты (лист 5×5, плоская альфа) не вернулись.

**Контраст к грунту:** по ядру клуба (без растушёванного края) разница светлоты — 26.7 / 32.8 / 51.0 / 52.7 (из 255) на четырёх измеренных клубах; порог из задания ~25 — все четыре выше или на границе. Слабее всего клубы на самой площадке (у кокпита Δ26.7, на бортике Δ32.8) — тёплый тинт слабее контрастирует с серо-голубым металлом, чем с оранжевым грунтом (Δ51-53 у двух клубов на грунте). Если считать разницу по всем пикселям клуба вместе с прозрачным краем — цифры ниже (15-27), но так и должно быть у мягкого спрайта с растушёванным краем, это не тревога.

**Рост по кадрам** (площадь diff>40 по 4 зонам): 0 мс — 0 px; 97 мс — 226 px (почти весь прирост в одной точке, остальные ещё не тронулись); 249 мс — 4592 px; 505 мс — 6494 px. Рост монотонный и уверенный. К 505 мс площадь ещё растёт, на полку не выходит — фаза «держатся 0.5 с» этой серией не покрыта: кадры обрываются ровно на границе заявленных 0.5 с, виден только рост, не удержание.

**Вердикт: ПРИНЯТО.** Пыль видна, лежит снаружи корпуса, стиль клубов правильный, контраст к грунту в плотной части достаточный, рост подтверждён числом. Два замечания ниже уровня отказа, но стоит знать: (1) диффом подтверждено 5 клубов из 7 заявленных — не хватает ракурса, чтобы увидеть дальнюю сторону кольца; (2) фаза удержания после роста кадрами не покрыта.
