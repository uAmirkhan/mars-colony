# Направление E: чем усилить самого помощника

Разведка инструментов под разработку игры (Mars Colony — web/PixiJS + TypeScript) и производство ассетов (Blender-конвейер).
Статус: в процессе, пишу по мере готовности, чтобы не потерять работу при обрыве связи.

Уже подключено, повторно не предлагается: Blender MCP (bpy, скриншоты, сводки сцены), Firecrawl (веб), fal.ai (генерация изображений/моделей).

Контекст проекта на момент разведки: `mars-colony` — Vite + React + TypeScript + PixiJS (2D canvas), тесты на Vitest + Playwright, есть `design/blender/` конвейер для 3D-рендера ассетов в 2D-спрайты. Unity/Godot/Unreal в стеке проекта не используются напрямую — ветки 1 и 4 ниже разведаны на будущее / на случай смены стека, честная оценка это учитывает.
