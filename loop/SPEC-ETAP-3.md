# Спека этапа 3 — «Полировка → первые 30 секунд → склад → экономика»

Решения заказчика 06.09 утром (интервью spec-pilot):
- Порядок этапа: **1 полировка вида → 2 первые 30 секунд → 3 склад до конца → 4 живая экономика.** Следующий блок начинается только после закрытия предыдущего.
- Пыль шаттла: сначала поиск готовых анимированных спрайт-листов дыма/пыли (CC0) в сети; Gemini для пыли не используем.
- Молнии остаются убранными до механики энергии.
- Недостающие элементы склада (vkladka-neaktivnaya, kapsula-emkost) заказчик генерирует сегодня.
- Анимации базовые входят в полировку.
- Критерий закрытия полировки — совет оценщиков (4 критика + судья), не вкус одного.

## Блок 1. Полировка вида

Цель: кадр читается как экран готовой казуальной игры, а не как сборка. Никаких новых механик.

1. **Аудит каждой зоны отдельно**, без подсказок от заказчика («не буду говорить, что плохо — пройдись по каждому»): верхний HUD (капсулы, бар, меню), карточка цели, склад и пузырь продажи, выделение и маяк, шаттл и площадка. По каждой зоне — арт-директор (замеры против Township) + критик кадра: список правок с местом и числом.
2. **Правки по списку**, одна причина на виток, парный кадр было/стало, приёмка инспектором.
3. **Базовые анимации** (`mars-juice`): нажатие кнопок (сжатие 6%, 80 мс), открытие/закрытие склада (масштаб 0.96→1, 120 мс) и пузыря, «+N» кредитов летит к счётчику, появление плашки имени. Проверка кадрами с фиксированным временем.
4. **Пыль шаттла**: `mars-uchenik` ищет спрайт-листы дыма/пыли (CC0/CC-BY, opengameart, kenney, itch), приносит 3 кандидата с лицензией; арт-директор выбирает по палитре; билборд-анимация листом (`PylSpraytami`). Траектория выше баков.
5. **Закрытие блока — совет оценщиков**: `mars-critic-kadr`, `mars-critic-igrok`, `mars-critic-proizvodstvo`, `mars-critic-sistema` + `mars-judge`. Блок закрыт, когда у критиков нет находок класса «ломает» и судья даёт V ≥ 85.

Не трогаем: позиции зданий, экономику, палитру (тёплый Township), элементы заказчика (только раскладка и анимация).

## Блок 2. Первые 30 секунд
Онбординг без текста: связь «посеять → собрать → продать → кредиты» видна с первого экрана; подсветка следующего шага; маяк ведёт по цепочке. Спека — `mars-onboarding`. Критерий — критик-игрок: «понятно за 3 секунды, куда нажать и зачем».

## Блок 3. Склад до конца
Вкладка «Модули» на vkladka-neaktivnaya, ёмкость на kapsula-emkost, состояние «полно», кнопка «Расширить» с ценой, продажа всех товаров, тултипы по спеке 2.4/2.6.

## Блок 4. Живая экономика
ColonyGame в сцену MAIN: производство по таймерам, поставки шаттлом по расписанию, цель считается, кредиты/опыт из домена, «что будет завтра» видно в кадре.

## Роли и правила
Как в `PROMPT-NOCH-2.md`: правит один, принимает другой; ворота `loop_gate` с критерием до правки; кадры — RunCommand через MCP (редактор открыт) или batch; настоящие клики для кнопок; чекпоинт каждые три витка; вырезка нейросетью; ошибки компиляции читать `Types: All` + сверять время dll.
