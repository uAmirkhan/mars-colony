# TRELLIS 2 на RTX 4090 — установка с нуля

Что это: нейросеть от Microsoft, которая превращает одну картинку в готовую 3D-модель
с текстурами. Бесплатно, лицензия MIT, работает целиком на твоей видеокарте, ничего
никуда не отправляет.

Одна модель считается 3-60 секунд в зависимости от выбранного качества.

## Что понадобится

- **RTX 4090** (нужно минимум 24 ГБ видеопамяти, у 4090 ровно столько)
- **60 ГБ свободного места** на диске
- **Свежий драйвер NVIDIA** — обновить через GeForce Experience или с nvidia.com
- Интернет: скачается около 20 ГБ
- Времени: 40-90 минут, но почти все это ожидание, руками работы минут на десять

Инструкция написана под **Windows**. Если стоит Linux — пропусти Часть 1 и начинай
с Части 2, все команды те же.

---

## Часть 1. Ставим Linux внутрь Windows (WSL2)

TRELLIS официально работает только на Linux. На Windows его запускают через WSL2 —
это встроенная в Windows подсистема Linux. Видеокарта в ней работает напрямую,
потери в скорости нет.

**1.1** Открой PowerShell **от имени администратора** (правой кнопкой по кнопке Пуск →
Терминал (администратор)).

**1.2** Выполни:

```powershell
wsl --install -d Ubuntu-24.04
```

**1.3** Перезагрузи компьютер, когда попросит.

**1.4** После перезагрузки откроется окно Ubuntu и попросит придумать имя пользователя
и пароль. Пароль при вводе не отображается вообще — это нормально, просто печатай
и жми Enter.

**1.5** Проверь, что видеокарта видна из Linux. В окне Ubuntu набери:

```bash
nvidia-smi
```

Должна появиться таблица с надписью **NVIDIA GeForce RTX 4090**. Если написано
«command not found» — обнови драйвер NVIDIA в Windows и перезагрузись.

> Дальше все команды выполняются в окне **Ubuntu**, а не в PowerShell.
> Открыть его потом можно через Пуск → Ubuntu.

## Часть 2. Базовые инструменты

**2.1** Обнови систему и поставь компилятор с git:

```bash
sudo apt update && sudo apt upgrade -y
sudo apt install -y build-essential git wget
```

Попросит пароль — это тот, что придумал в пункте 1.4.

**2.2** Поставь Miniconda (менеджер окружений, TRELLIS без него не собирается):

```bash
wget https://repo.anaconda.com/miniconda/Miniconda3-latest-Linux-x86_64.sh
bash Miniconda3-latest-Linux-x86_64.sh
```

Жми Enter, потом пролистай лицензию (можно зажать Enter), напиши `yes`, снова Enter,
и на последний вопрос про автозапуск ответь `yes`.

**2.3** Закрой окно Ubuntu и открой заново. В начале строки должно появиться `(base)` —
значит conda установилась.

**2.4** Поставь CUDA Toolkit 12.4 — без него не соберутся части, написанные под
видеокарту:

```bash
wget https://developer.download.nvidia.com/compute/cuda/repos/wsl-ubuntu/x86_64/cuda-keyring_1.1-1_all.deb
sudo dpkg -i cuda-keyring_1.1-1_all.deb
sudo apt update
sudo apt install -y cuda-toolkit-12-4
```

Это самый долгий шаг, около 3 ГБ загрузки.

**2.5** Пропиши путь к CUDA, чтобы система его находила:

```bash
echo 'export CUDA_HOME=/usr/local/cuda-12.4' >> ~/.bashrc
echo 'export PATH=$CUDA_HOME/bin:$PATH' >> ~/.bashrc
source ~/.bashrc
```

**2.6** Проверь:

```bash
nvcc --version
```

Должно написать `release 12.4`. Если пишет «command not found» — вернись к 2.5.

## Часть 3. Ставим сам TRELLIS 2

**3.1** Скачай проект:

```bash
git clone -b main https://github.com/microsoft/TRELLIS.2.git --recursive
cd TRELLIS.2
```

Флаг `--recursive` обязателен, без него не скачаются вложенные компоненты.

**3.2** Запусти установку:

```bash
. ./setup.sh --new-env --basic --flash-attn --nvdiffrast --nvdiffrec --cumesh --o-voxel --flexgemm
```

Точка и пробел в начале строки обязательны, это не опечатка.

Дальше **20-60 минут ожидания**. Скрипт создаст окружение, скачает библиотеки и
скомпилирует несколько модулей под видеокарту. По экрану побегут километры текста,
будут желтые предупреждения — это нормально, пугаться не надо. Ошибка выглядит как
слово `error` красным и остановка процесса.

Ноутбук в это время не усыплять.

**3.3** Когда закончится, активируй окружение:

```bash
conda activate trellis2
```

---

## Часть 4. Запуск

**4.1** В папке `TRELLIS.2` выполни:

```bash
python app.py
```

**Первый запуск скачает саму модель, около 16 ГБ.** Идет минут десять-двадцать, и
кажется, что все зависло — это не так, просто скачивание молчаливое. Дальше запуски
будут мгновенными.

**4.2** Когда появится строка вида `Running on local URL: http://127.0.0.1:7860`,
открой этот адрес в обычном браузере Windows.

**4.3** Откроется страница: слева перетаскиваешь картинку, справа получаешь 3D-модель,
которую можно покрутить мышкой и скачать кнопкой в формате **GLB**.

Настройка качества: `512` — быстро, 3 секунды. `1024` — заметно лучше, около 20 секунд.
`1536` — максимум, минута. Для начала бери 1024.

**4.4** Чтобы выключить — Ctrl+C в окне Ubuntu.

**Запуск в следующий раз:**

```bash
cd TRELLIS.2
conda activate trellis2
python app.py
```

## Какие картинки давать на вход

От этого результат зависит сильнее, чем от настроек:

- **Один объект на картинке**, без фона и без других предметов рядом
- **Ровный однотонный фон** — модель проще отделяет объект от него
- **Ракурс три четверти**, чтобы были видны сразу две-три стороны. Строго сбоку или
  строго спереди дает хуже: сеть не знает, что находится сзади, и додумывает
- Объект целиком в кадре, ничего не обрезано краем
- Разрешение от 1024 пикселей

## Если что-то пошло не так

**`nvidia-smi` не работает в Ubuntu** — обнови драйвер NVIDIA в Windows (не в Ubuntu,
внутрь Linux драйвер ставить не надо) и перезагрузись.

**Ошибка при сборке `flash-attn`** — обычно не хватило оперативной памяти при
компиляции. Закрой все программы и запусти `setup.sh` заново, он продолжит с места
остановки.

**`CUDA out of memory` при генерации** — выбери разрешение поменьше (512 вместо 1536)
и закрой игры и браузер, они тоже едят видеопамять.

**Совсем не собралось** — не мучайся, есть два запасных пути:
- `huggingface.co/spaces/microsoft/TRELLIS.2` — та же модель в браузере, бесплатно,
  ничего ставить не надо, но с очередью
- ComfyUI со сборкой TRELLIS — ставится на Windows без WSL, но это неофициальный путь

## Коротко о том, что получится

Бесплатный и безлимитный генератор 3D-моделей на своей машине. Лицензия MIT —
результат можно использовать где угодно, включая коммерческие проекты, без указания
авторства и без отчислений.

На выходе GLB с полным набором PBR-текстур: цвет, шероховатость, металличность,
прозрачность. Открывается в Blender, Unity, Unreal и любом другом движке.
