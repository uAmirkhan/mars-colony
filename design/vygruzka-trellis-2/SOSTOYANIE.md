## Как продолжить

```bash
# 1. ОБЯЗАТЕЛЬНО: проверить, что карта видна ИЗНУТРИ Ubuntu.
#    После сна или перезагрузки проброс ломается, и всё падает на
#    "CUDA driver error: device not ready". Лечится wsl --shutdown.
wsl -d Ubuntu-24.04 -u root -e nvidia-smi --query-gpu=name --format=csv,noheader

# 2. Отключить сон.
powercfg /change standby-timeout-ac 0
powercfg /change hibernate-timeout-ac 0

# 3. Продолжить очередь. Готовые пропускаются сами.
wsl -d Ubuntu-24.04 -u root -e bash -c "nohup setsid bash /root/partiya2.sh > /root/partiya2.log 2>&1 &"
```

Параметры зашиты в `/root/partiya2.sh`: `--potolok 20000 --setka 1024 --seed 42`,
текстура 2048.

## Оценка глазами: что вижу слабым

**Камни — главная проблема партии.** `kamen-gladkiy`, `kamen-granenyy`,
`kamni-para` остались картофелинами и при двадцати тысячах треугольников.
Значит бюджет тут ни при чём: генератор сглаживает плоские фасеты, читая их
как шум. Планирую собрать камни руками из икосферы в Blender — по разделу 7
задания это нормальное решение, и оно быстрее третьего круга параметров.

**`led-greben`** вышел тонкой лентой, в кадре потеряется. Дефект приходит из
входной картинки, а не из чисел: объект на ней нарисован узким и плоским.
Предлагаю перерисовать по промпту из `promty-led.md`, сделав гряду массивнее.

**`led-valun-v-shube`** — лёд облепил валун комками, граница льда и камня
читается плохо.

**Хорошо получилось:** все четыре фигуры (скафандр с ранцем, наплечниками и
стыками на рукавах), цистерна с заклёпками и вентилем, тоннельный модуль с
рамами окон, оба ледяных кристалла, гранёная глыба, полынья, гриб-купол,
ангар с панелями.
